# Allinpay-Assist-System

Allinpay-Assist-System 是一套聚合支付/收款辅助系统，主要用于便捷地管理商户、收款码、表单收款、账单收款及支付通道，满足多种业务场景下的自动化收款及对账需求。系统支持多商户管理、数据统计、API对接、订单对账、权限分级等功能，适合企业或开发者集成和二次开发。

## 功能特点

- **多场景收款**：支持收款码、表单收款、账单收款。
- **开放API接口**：完善的API文档，方便对接第三方系统，实现自动化收款。
- **数据统计与对账**：订单明细、对账单一站式管理，支持导出和多维度分析。
- **权限管理**：包含管理后台与用户权限相关模块。
- **灵活扩展**：模块化设计，便于二次开发和功能拓展。

## 目录结构

- `admin/`：管理后台模块，包括用户、商户、收款码、账单、支付通道等管理页面和功能。
- `bills/`：账单收款相关模块，包括项目管理、明细导入导出、账单支付、定时任务等。
- `codes/`：收款码相关功能，包括收款码生成、订单管理、定时查单脚本等。
- `commonpay/`：聚合支付通道相关模块，支持多通道订单管理、支付API等。
- `users/`：用户个人中心及相关功能。
- `forms/`：自定义表单收款管理。
- `merchants/`：商户资料管理。
- `static/`：前端静态资源（如样式表等）。
- `header.php` 等：通用头部、权限控制、公共函数等。

## 快速安装

1. 克隆代码到服务器
    ```bash
    git clone https://github.com/Lucian-Wang/Allinpay-Assist-System.git
    ```
2. 配置 PHP 运行环境及数据库，并导入相关数据表（见 `install.sql`）。
3. 配置根目录 `db.php`，并按商户信息配置支付通道；参考 `allinpay/config.sample.php`。
4. 设置网站根目录为项目根目录；仓库没有 `public/` 入口目录。
5. 后台地址：`/admin/`

## 主要模块说明

- **商户管理**：支持多商户资料录入及维护。
- **收款码管理**：支持为不同商户生成多种收款码，管理二维码及订单。
- **表单收款**：自定义收款表单，适用于活动报名、费用收缴等场景。
- **账单收款**：批量账单导入、明细管理、账单收款、导出对账。
- **支付通道管理**：支持多支付通道配置（如Allinpay通联支付），并可扩展其他通道。
- **API接口**：第三方系统可通过开放API快速集成收款功能，详见 `commonpay/apihelp.php`。

## 定时任务

- `bills/cron_query_recent_orders.php`、`codes/cron_query_recent_orders.php`：用于定时轮询未支付订单的最新支付状态，建议每5分钟执行一次。

## 开发与二次集成

- 可参考 `commonpay/apihelp.php` 获取API参数与调用说明。
- 代码结构清晰，便于扩展新的收款类型、支付通道或对接业务系统。

## 常见问题

- **通道标识如何获取？**  
  后台“通道管理”新建后自动分配，复制即可。
- **notify_url 可为空吗？**  
  可以，不填则不会推送支付结果到业务系统。
- **订单号重复会怎样？**  
  必须全局唯一，否则会报错或覆盖。
- **如何测试回调有效性？**  
  推荐用 webhook.site 观察回调内容。
